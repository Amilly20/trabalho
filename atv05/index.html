Linguagens e frameworks

Uma comparação para entender o papel de cada tecnologia na criação de sites.

COMPARAÇÃO

O que muda e o que elas têm em comum?

Algumas tecnologias estruturam e apresentam o conteúdo; outras ajudam a programar interações ou organizar aplicações completas. Elas podem ser combinadas no mesmo projeto.

Tecnologias de desenvolvimento web

08 tecnologias
Funções, semelhanças e diferenças entre linguagens e frameworks web
Tecnologia Tipo Para que serve Semelhanças Diferenças
HTML Linguagem de marcação Define a estrutura e o significado do conteúdo da página. Trabalha junto com CSS e JavaScript na construção de sites. Organiza o conteúdo; não é uma linguagem de programação nem define, por si só, a aparência visual.
CSS Linguagem de estilos Controla cores, tipografia, espaçamento, layout e adaptação a diferentes telas. É aplicada aos elementos HTML e pode ser combinada com bibliotecas e frameworks. Descreve a apresentação visual, enquanto HTML estrutura o conteúdo e JavaScript implementa comportamentos.
JavaScript Linguagem de programação Adiciona lógica e interatividade, como menus, validação de formulários e atualizações de conteúdo. É frequentemente usada com HTML e CSS no navegador. Executa instruções e comportamentos; não é, por si só, um framework.
TypeScript Linguagem baseada em JavaScript Acrescenta verificação de tipos para ajudar a encontrar erros durante o desenvolvimento. Usa a sintaxe e os recursos de JavaScript. O código TypeScript normalmente é convertido em JavaScript antes de ser executado pelo navegador.
React Biblioteca de interface Ajuda a criar interfaces divididas em componentes reutilizáveis. Assim como Vue e Angular, é usado para construir interfaces dinâmicas. É uma biblioteca JavaScript; roteamento e outras funções podem exigir ferramentas adicionais.
Angular Framework de aplicação Oferece uma estrutura integrada para desenvolver aplicações web, geralmente com TypeScript. Assim como React e Vue, permite criar interfaces baseadas em componentes. Inclui mais recursos e convenções no próprio framework, como roteamento e ferramentas de formulários.
Vue Framework progressivo de interface Cria interfaces reativas e pode ser adotado em uma parte de um site ou em uma aplicação completa. Compartilha com React e Angular a composição de interfaces com componentes. Pode ser incorporado gradualmente; a configuração e o conjunto de recursos escolhidos variam conforme o projeto.
Bootstrap Framework CSS Fornece estilos, componentes e um sistema de grid para acelerar a criação de páginas responsivas. Assim como outros frameworks, oferece padrões reutilizáveis para a interface. É voltado principalmente à apresentação com CSS; não substitui a estrutura HTML nem a lógica de JavaScript.
